# script

**English** | [Tiếng Việt](README.vi.md)

Userscripts for **Tampermonkey** / **Violentmonkey**.

Click **Install** and your userscript manager will open its install page. Scripts installed this way update automatically.

| Script | Description | Install |
|---|---|---|
| [Gom Media](gom-media/) | Scans a XenForo thread and downloads all of its images and videos, as a ZIP or as separate files. Includes a full-screen viewer. Tuned for voz, xamvn and rphang. | [Install](https://raw.githubusercontent.com/loooveee/script/main/gom-media/gom-media.user.js) |
| [Clean Site Data](clean-site-data/) | Shows how much storage the current site uses and clears its data: cookies, Local/Session Storage, IndexedDB, Cache Storage, Service Workers, OPFS. | [Install](https://raw.githubusercontent.com/loooveee/script/main/clean-site-data/clean-site-data.user.js) |
| `qmh.user.js` | QMH Monster Ads Remove & Downloader. Original script from [siritami/script](https://github.com/siritami/script), kept unchanged from the upstream repo. The code is obfuscated, so its contents can't be reviewed. | [Install](https://raw.githubusercontent.com/loooveee/script/main/qmh.user.js) |
