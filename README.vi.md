# script

[English](README.md) | **Tiếng Việt**

Các userscript dùng với **Tampermonkey** / **Violentmonkey**.

Bấm **Cài đặt**, trình quản lý script sẽ mở trang cài. Script cài theo cách này sẽ tự cập nhật.

| Script | Mô tả | Cài đặt |
|---|---|---|
| [Gom Media](gom-media/README.vi.md) | Quét và tải toàn bộ ảnh, video trong thread XenForo (ZIP hoặc tải lẻ), có trình xem toàn màn hình. Tối ưu cho voz, xamvn, rphang. | [Cài đặt](https://raw.githubusercontent.com/loooveee/script/main/gom-media/gom-media.user.js) |
| `qmh.user.js` | QMH Monster Ads Remove & Downloader. Script gốc của [siritami/script](https://github.com/siritami/script), giữ nguyên từ repo gốc. Mã đã bị làm rối, không đọc được nội dung. | [Cài đặt](https://raw.githubusercontent.com/loooveee/script/main/qmh.user.js) |
